# Anime Face Generator 🎨

This project uses a Deep Convolutional Generative Adversarial Network (DCGAN) to generate realistic anime-style face images from random noise vectors.

## 🧠 Techniques Used
- GANs (Generative Adversarial Networks)
- DCGAN architecture
- PyTorch
- Image preprocessing and transformation
- MPS support for Apple Silicon (M1/M2)

## 🧾 Dataset
Anime Face Dataset from [Kaggle](https://www.kaggle.com/datasets/splcher/animefacedataset)
